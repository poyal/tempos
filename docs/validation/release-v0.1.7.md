# Tempos v0.1.7 Windows 배포 검증

각 빌드에서 실행한 E2E 382개는 외부 API를 목업으로 사용했다. 원본 결과는 `test-results/full-validation-20261125-095212`와 `test-results/full-validation-20261125-095359`에 있다. 센서 패키징 검사 22개도 통과했다. 버전을 올리기 전에 수행한 전체 회귀와 실제 입력 검사의 제약은 [설정 수정 전후 비교 기록](navigation-2026-11-25/results.md)에 따로 남겼다.

서명 패치 ZIP의 333개 파일을 설치 패키징 목록과 개별 크기·해시로 대조했다. 무설치판과 설치판 문서에서 각각 40개 문서, 505개 로컬 링크·앵커와 135개 PNG 해시를 검사했다. GitHub 초안의 자산 여덟 개를 빈 폴더로 내려받아 로컬 원본·GitHub digest와 대조하고, 저장소 공개 키로 메타데이터 서명을 검증했다.

깨끗한 Windows Server 2022 러너에서 실제 공개 v0.1.6 설치 파일로 시작해 서명 패치로 v0.1.7을 적용했다. 새 프로세스 기동, Windows 설치 버전 등록, 파일별 해시, 제거 후 기존 사용자 파일·시계 설정 보존을 확인했다. 개발 PC의 설치 앱은 이 검사에 사용하지 않았다. [GitHub Actions 실행](https://github.com/poyal/tempos/actions/runs/45522329781)

검증한 초안을 최신 정식 릴리즈로 공개했다. 공개 URL에서 인증 없이 자산 여덟 개를 다시 받았고 크기와 SHA-256이 로컬 원본 및 GitHub 메타데이터와 일치했다. 공개 파일의 Ed25519 서명도 확인했다. [정식 릴리즈](https://github.com/poyal/tempos/releases/tag/v0.1.7) · [공개 파일별 해시와 주소](release-v0.1.7-published.json)
