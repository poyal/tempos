## 실패·중단 보존

- 센서 테스트의 최초 파이프 ACL이 테스트 실행 소유자를 허용하지 않아 연결 시간 초과 및 처리되지 않은 .NET 예외창이 발생했다. 소유자 권한, 최상위 예외 처리, Windows 오류창 억제를 추가한 뒤 22개 통과했다.
