## 실제 환경과 계산/목업의 구분

- 혼합 DPI·모니터 분리/재연결은 계산 모델로 검사한다. 현재 연결되지 않은 실장비를 테스트한 것으로 기록하지 않는다.
- 실제 GPU 온도는 드라이버가 값을 제공할 때만 검사한다. 센서 서비스 설치·제거는 목업과 별도 센서 단위 검사로 검증하며 설치본에는 적용하지 않는다.
- 현재 사용자 세션 재로그인과 기존 설치본의 설치·제거는 보호 조건상 실행하지 않는다.
- 외부 앱에 가려진 일반 위젯은 화면 입력 검사만 SKIP하며 저장/창/프로세스 검사는 수행한다.
