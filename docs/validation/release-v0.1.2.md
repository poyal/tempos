# v0.1.2 릴리즈 검증

2026-10-17 Windows 11 x64에서 검사한다. 앱 동작 변경과 [전후 디자인 보고서](2026-10-17-layout-report.html)는 먼저 검증했고, 공개 버전을 0.1.2로 올린 최종 바이너리로 Release·ASan 핵심 검사와 관련 Windows E2E를 다시 실행한다. 최종 실행별 결과·해시는 완료 후 이 문서와 JSON에 기록한다.

외부 날씨·위치·Google Calendar·OAuth 요청은 HTTP 경계 목업이다. `--windows-real`에서만 로컬 Windows 시스템 자료를 실제로 읽으며, 디자인 캡처와 센서 응답/설치 결과 목업은 실측으로 표시하지 않는다. 실제 외부 API·실제 Windows 재로그인은 검사하지 않는다.

기존 Tempos 설치가 있으므로 설치·제거 수명주기와 CPU 서비스/PawnIO 설치·제거는 실행하지 않는다. 사용자 앱·원본 레이아웃·자동 시작 값을 보존하고 각 E2E는 별도 TestHost와 실행별 데이터 폴더를 사용한다. 실패·SKIP 및 개발 중 결과는 최종 통과 수와 분리한다.
