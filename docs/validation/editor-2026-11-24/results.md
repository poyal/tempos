# 설정 및 위젯 개편 검사 기록

2026년 11월 24일 Windows x64 개발 빌드를 대상으로 수행했습니다. [설정과 위젯 전후 비교](index.html)

## 화면 비교 조건

- 이전 화면은 10월 17일 매뉴얼의 원본 PNG입니다. 새 화면은 격리된 TestHost의 위젯 9종과 지원되는 크기 37개입니다. 시각 비교에는 예제 수집기와 모의 날씨·일정을 사용했습니다. 전후 촬영 배율이 다른 화면은 비교 페이지에서 같은 논리 너비로 표시합니다. 각 이미지 링크는 원본 픽셀을 보존합니다. 두 촬영의 시각·일정·장치 제목은 다를 수 있습니다.
- 모니터 배율은 100%였습니다. 위젯 확대 100%, 150%, 200%에서는 가용 화면에 들어가는 구성의 외곽 크기와 위치 저장을 확인했습니다. 화면보다 큰 구성은 적용이 거절되고 이전 위치가 유지되는지 검사했습니다. 연결되지 않은 모니터는 시험 배치에 없는 모니터 ID를 지정해 재현했습니다. 실제 혼합 DPI 모니터 간 이동은 검증 범위 밖입니다.
- 설정 테마는 테스트 폴더에서 밝게·어둡게·고대비 예제를 지정했습니다. Windows 개인 설정은 변경하지 않았습니다.
- 외부 창이 가린 영역은 Windows의 설정창 인쇄 또는 위젯이 실제로 그린 표면에서 원래 해상도로 얻었습니다. 외부 창에 가려진 마우스 적중은 별도로 SKIP 처리했습니다.
- 단위 검사는 저장·복구와 구버전 호환성을 포함합니다. 일반 E2E는 실제 Windows UI·파일·재시작을 사용하며, 날씨·Google Calendar·OAuth·위치는 목업 경계에서 응답합니다. 로컬 카운터는 `--windows-real`에서 실제로 수집했습니다.

## 재검사에서 수정한 항목

- 작은 CPU·GPU 위젯에서 온도 글자가 사용률 막대에 닿았고, 작은 디스크 위젯은 막대가 하단 여백을 침범했습니다. 원본 크기로 수정 후 비교하고 작은 온도 위젯의 줄 간격과 37개 구성의 하단 픽셀을 검사했습니다.
- 현재 위치 조회가 끝난 뒤 버튼이 비활성 상태로 남던 문제를 수정했습니다. 모의 위치를 선택하고 적용·재시작하는 경로로 확인했습니다.
- 외부 창이 가린 화면에서 단색 이미지가 검수를 통과하는 문제를 수정했습니다. 캡처 시 소유 창과 실제 색상 분포를 확인하고, 파일 대화상자에서는 대상 입력란에 직접 경로를 전달합니다.
- 초기 위젯 한 개의 드래그 종료 지연은 p95 129ms로 100ms 기준을 초과했습니다. 유효한 이전 설정 파일을 백업할 때 하드 링크를 지원하는 저장소에서는 이미 디스크에 기록된 이전 파일을 재사용합니다. 기본 파일은 임시 파일을 완전히 기록한 뒤 교체하며, 하드 링크를 지원하지 않는 볼륨에서는 복사 방식으로 백업합니다.

트레이 전환은 메뉴가 보내는 배치 선택 명령을 TestHost에 전달해 저장·복원까지 확인했습니다. 작업 표시줄의 숨겨진 아이콘을 마우스로 열어 메뉴를 선택하는 과정은 이 검사에 포함되지 않습니다.

### 성능

기본 M 위젯 5개를 띄우고 같은 PC에서 설정창 상태별로 30초 준비 후 약 60초씩 측정했습니다. CPU는 전체 논리 프로세서 기준이며 메모리는 측정 구간 최댓값입니다.

| 설정창 | 평균 CPU | p95 CPU | Private | Working Set | 미리보기 그리기 | 필수 예산 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 닫힘 | 0.013% | 0.128% | 19.80 MiB | 43.04 MiB | 0회 | 통과 |
| 열림 | 0.039% | 0.130% | 22.54 MiB | 43.04 MiB | 2회 | 통과 |

평균 CPU 시간은 닫힘 1.54ms/초, 열림 4.64ms/초였습니다. 4ms/초 이하의 추가 최적화 목표는 닫힘 충족, 열림 초과입니다.

드래그는 100회 준비 후 위젯 수별로 1,000회씩 측정했습니다. 위젯 한 개의 이동 p95는 0.99ms, 파일 저장을 포함한 놓기 p95는 39.36ms였습니다. 64개 밀집 배치의 이동과 놓기는 각각 0.53ms와 2.81ms였습니다.

이 측정은 현재 PC의 단기 회귀 검사입니다. 30분 부하·두 번째 PC·전력 사용량은 측정하지 않았습니다.
