## 검수 범위와 차이 기록

자동화 통과와 사람이 화면을 읽고 판단한 결과를 따로 기록한다. 캡처만 생성하고 검수 완료로 취급하지 않는다. 각 구성의 실제 화면, 9개 테마, 날씨 상태, 설정 4개 탭, 빈 화면·오류·투명도·배치를 확인한다. 모든 크기×배율×테마×상태의 곱 전체를 육안 확인했다고 주장하지 않는다.

시안의 설정 패널은 방향 참고다. 현재 설정은 Win32 네이티브 탭·콤보·입력란을 사용한다. 실시간 미리보기/취소, 슬라이더, 오른쪽 배치 편집 패널 등 구현되지 않은 시안 요소는 검수 결과에서 차이로 공개한다. 이를 구현된 기능으로 바꿔 적거나 임의의 합격으로 덮지 않는다.
