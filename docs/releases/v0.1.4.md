# Tempos v0.1.4 · Windows 11 x64

설정에 **About · 업데이트**를 추가했습니다. 현재 버전과 제작자, 사용 안내·GitHub·문의 링크를 확인하고 새 정식 버전을 설치할 수 있습니다.

**[Windows 설치 EXE](https://github.com/poyal/tempos/releases/download/v0.1.4/Tempos-0.1.4-win-x64.exe)** · [SHA-256](https://github.com/poyal/tempos/releases/download/v0.1.4/Tempos-0.1.4-win-x64.exe.sha256) · [무설치 ZIP](https://github.com/poyal/tempos/releases/download/v0.1.4/Tempos-0.1.4-win-x64.zip) · [사용법](../../README.md)

- 앱 시작 시 새 정식 버전을 한 번 확인합니다. 자동 확인을 끄고 직접 확인할 수도 있습니다. 확인 시각은 PC의 현지 시각으로 표시합니다.
- 설치형에서 **업데이트 설치**를 누르면 다운로드·크기 및 SHA-256 검증 후 앱 종료·설치·재실행까지 진행합니다. 저장된 위젯 설정과 연동 정보는 유지하며, 적용하지 않은 변경은 먼저 적용해야 합니다.
- 다운로드 도중 취소하거나 앱을 종료할 수 있습니다. 통신·파일 검증 실패 때는 현재 앱을 유지하고 재시도를 안내합니다. 설치 결과는 About에 표시합니다.
- 같은 버전·이전 버전·사전 공개 버전은 설치하지 않습니다. 다른 주소로 향하는 설치 파일, 크기·해시가 맞지 않는 파일을 거부합니다.
- 무설치 실행에서는 등록된 설치본을 변경하지 않고 릴리즈 페이지에서 ZIP을 받아 교체하도록 안내합니다. 시작 확인 설정은 레이아웃 내보내기에서 제외하며 가져와도 이 PC의 값을 유지합니다.

**v0.1.3 이하에서는 이번 설치 EXE로 한 번 수동 업데이트해 주세요.** 기존 Tempos를 완전히 종료한 뒤 EXE를 실행하면 됩니다. 이후 버전부터 앱 안의 업데이트 기능을 사용할 수 있습니다.

[최종 후보 검증·제한](../validation/release-v0.1.4.md), [개발 단계 검증](../validation/2026-11-14-about-updates.md). 외부 API는 HTTP 경계 목업으로 검사했습니다. 업데이트 도우미·앱 종료·재실행은 실제 TestHost로 검증하되 설치 프로그램은 목업 프로세스입니다. 기존 설치본 보호 기준에 따라 실제 NSIS 설치·파일 교체와 외부 GitHub 실연동은 수행하지 않았으며, 해당 결과를 실제 설치 성공으로 표시하지 않습니다.
