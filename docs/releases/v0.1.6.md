# Tempos v0.1.6

설치형에서 **정보 및 업데이트 → 업데이트 다운로드**를 누르면 패치를 받아 두고 위젯을 계속 사용할 수 있습니다. **재시작하여 적용**을 누르면 위젯 편집을 마무리한 뒤 새 버전을 적용합니다. 이미 받은 패치는 앱을 다시 열어도 사용할 수 있습니다.

- 앱이 배포자의 Ed25519 서명과 패치 ZIP의 크기·SHA-256을 확인합니다.
- 새 버전이 설정을 읽고 위젯을 열어 기동을 확인한 뒤 완료로 표시합니다. 교체나 기동에 실패하면 이전 버전과 설정을 복원합니다.
- v0.1.4·v0.1.5 설치 사용자는 기존 **업데이트 설치**로 v0.1.6을 받습니다. 그다음 업데이트부터 새 흐름을 사용합니다. 처음 설치하거나 수동 복구할 때는 `Tempos-0.1.6-win-x64.exe`, 무설치판은 `Tempos-0.1.6-win-x64.zip`을 받으세요. `Tempos-0.1.6-win-x64-update.zip`은 앱 내 패치용입니다.
