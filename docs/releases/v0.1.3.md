# Tempos v0.1.3 · Windows 11 x64

위젯 배치와 격자 정렬을 보완하고, 설정창을 닫거나 화면 가장자리에서 드래그할 때 생기던 문제를 수정했습니다.

**[Windows 설치 EXE](https://github.com/poyal/tempos/releases/download/v0.1.3/Tempos-0.1.3-win-x64.exe)** · [SHA-256](https://github.com/poyal/tempos/releases/download/v0.1.3/Tempos-0.1.3-win-x64.exe.sha256) · [무설치 ZIP](https://github.com/poyal/tempos/releases/download/v0.1.3/Tempos-0.1.3-win-x64.zip) · [사용법](../../README.md)

- 스냅 간격을 4 DIP에서 8 DIP로 넓히고 표시 격자도 같은 간격으로 맞췄습니다. 위젯 사이 여백은 유지하며, 배율에 따른 크기를 보정해 왼쪽·오른쪽·위·아래 외곽이 같은 격자 규칙에 맞도록 했습니다.
- 오른쪽 경계나 다른 위젯 근처에 놓을 때 가까운 유효 위치를 찾도록 개선했습니다. 공간이 없을 때는 기존 위치를 유지합니다.
- 설정창을 닫으면 편집 모드와 격자가 함께 해제됩니다. 배치를 다시 만드는 동안 남아 있던 드래그 상태도 정리합니다.
- 이동 결과가 같거나 배치가 거절된 경우 불필요한 설정 저장을 줄였습니다. 기존 4 DIP 레이아웃은 새 크기에 맞춰 가까운 위치로 복원합니다.
- 글자 배치와 정적 배경의 제한된 캐시를 추가하고 그래프 그리기를 개선했습니다. 데이터 갱신 주기는 유지합니다.

핵심·ASan·격자/배율·드래그·저장/재시작·실제 Windows 입력·장시간 자원 검사를 확장했습니다. 외부 날씨·Google·위치 API는 HTTP 경계 목업으로 검사했으며, 실제 API 연결 성공으로 표시하지 않습니다. [격자 회귀 검증](../validation/2026-11-14-grid-regression.md), [두 PC의 성능 검증](../validation/2026-11-14-personal-two-windows.json), [릴리즈 후보 검증](../validation/release-v0.1.3.md).

개발 단계의 두 PC 기본 M 위젯 5개 성능 검사에서는 각각 30분 동안 평균 CPU 시간 4.98ms/초와 1.87ms/초를 측정해 새 필수 예산 10ms/초를 충족했습니다. 4ms/초는 별도의 절약 목표이며 현재 PC는 미달입니다. 이 결과는 버전 리소스 변경 전 빌드의 기록으로, 새 릴리즈 파일의 30분 재측정 결과와 혼동하지 않습니다.

업데이트하려면 Tempos를 종료한 뒤 설치 EXE를 실행합니다. 설정과 레이아웃은 유지됩니다. 기존 설치가 있는 검증 PC에서는 사용자 앱을 종료하거나 설치·제거 검사를 수행하지 않았습니다. 실제 센서 값이 없는 CPU/GPU 온도, 서비스·드라이버 설치 및 외부 API 실연동은 별도 확인 대상입니다.
