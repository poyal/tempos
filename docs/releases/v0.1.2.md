# Tempos v0.1.2 · Windows 11 x64

CPU·GPU 온도를 사용률과 함께 표시하고, 높은 온도와 사용률을 색상으로 구분합니다. 날씨·시스템 정보·캘린더의 배치를 다듬어 작은 위젯에서도 필요한 정보를 읽기 쉽게 했습니다.

**[Windows 설치 EXE](https://github.com/poyal/tempos/releases/download/v0.1.2/Tempos-0.1.2-win-x64.exe)** · [SHA-256](https://github.com/poyal/tempos/releases/download/v0.1.2/Tempos-0.1.2-win-x64.exe.sha256) · [무설치 ZIP](https://github.com/poyal/tempos/releases/download/v0.1.2/Tempos-0.1.2-win-x64.zip) · [사용법](../../README.md)

- CPU·GPU: M은 사용률 옆에 온도를, M·L은 맨 아래 전체 폭에 모델명을 표시합니다. S·Slim에서는 모델명을 숨깁니다. 온도는 `45°C`처럼 표시하며 지원되지 않거나 오래된 값은 `—`로 표시합니다.
- 색상: 온도는 80°C·90°C, CPU/GPU 사용률은 80%·95%, 메모리/디스크 사용률은 80%·90%에서 흰색 → 주황색 → 빨간색으로 바뀝니다. 기기별 안전 한계나 고장 판정이 아닌 앱 표시 기준입니다.
- 날씨: 현재 상태와 최저·최고를 한 줄로 정렬하고 L에는 다음 4일의 날짜·날씨·최고/최저·강수확률을 표시합니다. 예보가 없는 날짜는 값을 만들어 채우지 않습니다.
- 디스크: 선택 목록에서 사용 불가 드라이브를 제외합니다. 네트워크 그래프와 최근 60초 문구의 간격을 조정했습니다.
- 캘린더: S는 연도 없이 월·날짜를 한 줄로 표시하고 XL의 요일 위 테두리를 보완했습니다.

CPU 온도는 설정에서 선택 설치하는 [센서 도우미](../sensors.md)가 필요합니다. 도우미 설치 시 관리자 승인을 요청하며, GPU 온도는 Windows 드라이버가 제공하는 값을 사용합니다. 도우미 검사 실행 시 발생하던 예외와 파이프 접근 권한도 보완했습니다.

[HTML 전후 비교 보고서](../validation/2026-10-17-layout-report.html)에 37개 구성의 스크린샷, 빨간 변경 표시, 유지 항목과 색상별 예제를 담았습니다. 보고서 이미지는 디자인 예제/목업입니다. [최종 릴리즈 검증과 제한](../validation/release-v0.1.2.md).

업데이트하려면 Tempos를 종료한 뒤 설치 EXE를 실행합니다. 저장된 설정과 레이아웃은 유지됩니다. 기존 설치 보호 기준에 따라 이번 작업에서는 사용자 앱을 종료하거나 실제 설치·제거, CPU 서비스/PawnIO 설치를 실행하지 않습니다. 외부 API의 실연동도 별도 검사 대상입니다.
