# Tempos v0.1.1 · Windows 11 x64

두 번째 모니터에서 정렬 모드를 켜고 끈 뒤 다시 켜면 목록은 남아 있는데 위젯 그림이 사라지는 문제를 수정했습니다.

**[Windows 설치 EXE](https://github.com/poyal/tempos/releases/download/v0.1.1/Tempos-0.1.1-win-x64.exe)** · [SHA-256](https://github.com/poyal/tempos/releases/download/v0.1.1/Tempos-0.1.1-win-x64.exe.sha256) · [무설치 ZIP](https://github.com/poyal/tempos/releases/download/v0.1.1/Tempos-0.1.1-win-x64.zip) · [사용법](../../README.md)

- 150% 기본 모니터와 125% 보조 모니터 사이에서 바탕화면 부모를 전환할 때 투명 창 상태를 재설정합니다. 전환 도중 DPI 알림으로 위치·그리기 처리가 다시 실행되는 것도 막았습니다.
- 정렬 중에는 격자와 위젯을 앞에 표시하고, 종료하면 저장한 **항상 위** 설정으로 돌아갑니다. 설정창은 정렬 레이어보다 앞에 표시합니다.
- E2E 전용 앱은 별도 설정 경로가 없거나 설치된 사용자 프로파일을 가리키면 실행을 거부합니다. 프로파일마다 창·단일 실행 식별자를 구분하고, 검사 전후 설치 레이아웃·백업·자동 시작 등록이 그대로인지 확인합니다.

업데이트하려면 **Tempos 종료** 후 설치 EXE를 실행해 기존 폴더에 설치하세요. `%LocalAppData%\Tempos`의 설정과 레이아웃은 유지합니다. 이 수정 작업은 사용 중인 설치 앱을 종료하거나 덮어쓰지 않았습니다.

실제 두 모니터에서 레이아웃 복사본으로 반복 전환과 위젯 화면을 확인합니다. 외부 API는 목업이며 원본 설정은 변경하지 않고 인증 정보는 복사하지 않습니다. 레이아웃 복사본에는 위젯 배치와 표시 설정만 들어갑니다. 설치·제거 E2E는 기존 설치가 있으면 중단하도록 유지합니다. [검증과 제외 범위](../validation/release-v0.1.1.md).
