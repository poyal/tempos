# Tempos v0.1.7

- 설정 페이지의 목록이나 입력란을 사용한 뒤 다른 메뉴를 누르면 이전 메뉴까지 파랗게 남던 문제를 수정했습니다. 현재 열린 메뉴 한 곳만 강조됩니다.
- 기본 위젯 다섯 개가 목록에 온전히 보이도록 글자 높이와 화면 배율에 맞춰 목록 높이를 계산합니다.
- 위젯을 편집하다 다른 위젯을 선택하고 **적용**을 눌렀을 때, 목록에서 강조된 위젯과 편집기가 보여주는 위젯이 일치합니다.

**v0.1.6 설치형**에서는 **설정 → 정보 및 업데이트 → 업데이트 확인 → 업데이트 다운로드 → 재시작하여 적용**으로 받을 수 있습니다. 처음 설치하거나 수동으로 업데이트하려면 `Tempos-0.1.7-win-x64.exe`를, 무설치판은 `Tempos-0.1.7-win-x64.zip`을 받으세요.
