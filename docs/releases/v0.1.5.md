# Tempos v0.1.5 · Windows 11 x64

위젯의 이름과 모양, 표시할 정보를 한 화면에서 편집하고 미리보기로 확인할 수 있습니다. 작업용과 휴식용처럼 자주 쓰는 위젯 배치를 저장해 두고 트레이에서 전환할 수 있습니다.

- **위젯 편집**에서 크기·테마·단위를 바꾸면 미리보기에 반영됩니다. **적용**으로 저장하거나 **되돌리기**로 마지막 적용 상태로 돌아갑니다. 같은 설정을 한 번 더 쓰려면 **복제**를 누르세요.
- **배치**에서 현재 구성을 복사하고 이름을 붙일 수 있습니다. 재시작하면 마지막으로 사용한 배치가 열립니다. 기존 레이아웃은 처음 실행할 때 기본 배치로 옮겨집니다.
- 작은 CPU·GPU 위젯은 온도와 사용률 막대 사이를 띄웠습니다. 디스크 사용률 막대와 위젯 하단 사이에도 여백을 확보했습니다. 날씨에서 현재 위치를 조회한 뒤 다시 조회할 수 있도록 수정했습니다.

v0.1.4 설치형에서는 **설정 → About · 업데이트 → 업데이트 확인 → 업데이트 설치**를 이용하세요. 무설치 버전은 앱을 종료한 뒤 새 ZIP을 풀어 실행하세요.
