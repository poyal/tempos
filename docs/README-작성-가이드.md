# Tempos README 작성 가이드

여백·Perilog·Passport의 사용자 매뉴얼 구성을 참조해 Tempos의 Windows 설치형·ZIP 배포와 네이티브 위젯에 맞춘다. 2026-10-17 전면 개편 기준이며 다른 프로젝트의 플랫폼 명령과 검증 결과는 가져오지 않는다.

## 목적과 구성

루트 README는 **Tempos 사용자 매뉴얼**이다. 한국어 존댓말로 처음 설치한 사용자가 기본 작업을 끝낼 수 있게 쓴다. 기능·버전 홍보나 개발 명령 목록으로 대체하지 않는다.

첫머리는 앱 소개·다운로드·전체 예시·9종 위젯 요약·목차로 구성한다. 본문 순서는 설치 → 화면·트레이·종료 → 위젯 추가·배치 → 9종 위젯 상세 → 표시 옵션 → 날씨 → 캘린더 → CPU 온도 → 자동 시작 → 백업·복원 → 업데이트·제거 → 문제 해결이다. 위젯별로 표시 정보·크기별 차이·설정 순서·사용 조건을 설명한다. 목차와 위젯 요약은 명시적 앵커와 연결한다. 실제 메뉴·버튼은 굵게 쓰고 작업은 **진입 → 입력·선택 → 적용·저장 → 결과 확인** 순서로 적는다.

구현의 버튼명·저장 시점과 대조한다. 창 닫기/종료, 미적용 입력/저장값, 위젯별 설정/전역 공급자, 레이아웃 백업/인증 정보, 다운로드/파일 교체를 각 작업 옆에서 설명한다.

## 화면과 문서 역할

실제 앱 영역을 격리된 예제 데이터로 촬영하고 해당 설명 가까이에 둔다. 이미지에 alt와 원본 확대 링크를 넣고 [화면 안내](screenshots.md)에 실행 조건·출처를 기록한다. 디자인 시안을 실행 화면으로 쓰거나 개인 키·일정·바탕화면을 공개하지 않는다. 이번 개편은 37개 위젯 크기와 사용법 화면을 전면 재촬영했다. 새 촬영본은 날짜별 폴더에 저장하며 이전 이미지·해시·실연동 기록은 보존한다. 이후 변경하지 않은 캡처는 촬영 날짜를 보존해 재사용할 수 있다.

README는 기본 사용법, 사용 안내는 상세 옵션, 개발 안내는 구조와 명령, E2E 안내는 검사 방법, 검증 기록은 실제 결과, 배포 안내는 산출물 확인을 담당한다. 커밋·해시·검사 개수는 사용자 조작 설명에 섞지 않는다. 관련 안내를 함께 갱신한다.

공개 릴리즈가 확인되면 최신 릴리즈 다운로드 링크를 안내한다. 게시하지 않은 파일을 공개 다운로드 가능하다고 쓰지 않는다. 별도 게시 요청 없이 릴리즈를 만들지 않는다.

## 완료 전 확인

1. 현재 구현과 메뉴·버튼·단위·저장 결과를 대조한다.
2. 상대 링크·앵커·이미지·표와 `git diff --check`를 확인한다.
3. 새 캡처는 직접 열어 글자 잘림과 개인 정보 여부를 검토한다.
4. 수행한 검사와 미실행 항목을 구분해 기록한다.

문구·링크·이미지 배치만 바뀌면 전체 빌드·E2E를 반복하지 않는다. 앱 코드가 바뀌면 변경 범위에 맞는 검사를 수행한다.
