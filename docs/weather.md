# 날씨 서비스 연결

**연동 → 날씨 서비스 → 날씨 서비스 적용**에서 기상청과 Open-Meteo 중 하나를 고릅니다. 모든 날씨 위젯이 같은 서비스를 사용합니다. 위젯마다 국내 지역은 다르게 지정할 수 있습니다. 해외 도시 검색은 제공하지 않습니다.

## Open-Meteo

신규 설치의 기본값입니다. API 키나 회원가입 없이 국내 지역표의 위경도로 현재값·시간별 예보·당일 최저/최고를 요청합니다. 현재값은 기상 모델 자료입니다. 위젯에는 출처 문구를 붙이지 않으며 **연동 → 날씨 서비스**에서 Open-Meteo 선택과 안내를 확인합니다. [API 문서](https://open-meteo.com/en/docs)

무료 API는 비상업적 이용에 제공됩니다. 광고·구독이 있는 앱 등 상업적 사용에는 별도의 서비스 조건이 적용됩니다. 데이터의 CC BY 4.0 출처 표시와 무료 API 이용 조건은 별개입니다. 앱은 자료의 단위와 날씨 코드를 변환해 표시하며 출처·링크를 유지합니다. [이용 조건](https://open-meteo.com/en/terms) · [요금·호출 제한](https://open-meteo.com/en/pricing)

2026-10-12 확인 기준 무료 서비스는 분당 600회, 시간당 5,000회, 일당 10,000회 제한을 안내하며 요금 페이지에는 월 300,000회도 안내합니다. 제한은 앱 인스턴스별 보장량이 아닙니다. 실제 사용 전 공식 조건을 확인하세요.

## 기상청

1. [기상청 API허브](https://apihub.kma.go.kr/)에서 본인 인증키와 필요한 API 이용 권한을 준비합니다.
2. Tempos에서 **기상청**을 선택하고 **날씨 서비스 적용**을 누릅니다.
3. **기상청 API허브 인증키**에 키를 입력하고 **날씨 인증키 저장**을 누릅니다.
4. 날씨 위젯의 **날씨 지역 → 적용**으로 국내 지역을 지정합니다.

공공데이터포털의 `ServiceKey`와 다른 인증키입니다. 개인 키는 PC에 암호화해 보관하며 앱에 공용 키를 내장하지 않습니다. 실황 기온·습도·풍속·강수와 초단기 하늘 상태·시간별 예보, 단기 최저/최고를 조합합니다. 하늘 상태는 예보 자료를 사용할 수 있습니다. [동네예보 API 안내](https://apihub.kma.go.kr/apiList.do?seqApi=10)

기상청 서비스명과 안내는 연동 탭에서 확인합니다. 기존 설정 파일과 공급자 필드가 없는 레이아웃은 기상청을 기본으로 읽습니다.

## 전환·갱신·오류

- 선택 상자만 바꾸면 아직 적용되지 않습니다. **날씨 서비스 적용**의 저장 성공 뒤 모든 날씨 위젯이 바뀝니다. 저장 실패 시 기존 값과 선택 표시를 유지합니다.
- Open-Meteo로 전환해도 기상청 키를 삭제하지 않습니다. 기상청으로 돌아가면 같은 키를 사용할 수 있습니다.
- 외부 요청은 기상청 최소 10분, Open-Meteo 최소 15분입니다. 5분 표시 주기나 새로고침도 서비스 캐시와 재시도 제한을 우회하지 않습니다. 인증키 변경은 기상청 요청을 다시 준비합니다.
- 같은 위치와 공급자를 사용하는 위젯들은 결과를 공유합니다. 공급자 변경 전 시작한 요청은 새 서비스 화면을 덮어쓰지 않습니다.
- 타임아웃·서버 오류·한도 초과 시 같은 서비스·위치의 마지막 정상 자료를 갱신 지연 상태로 유지합니다. 키 오류나 한도 때문에 다른 공급자로 자동 전환하지 않습니다.
- 현상 자료가 2시간 이상 지연되면 날씨 배경을 중립화합니다. 마지막 자료가 24시간 이상 오래되면 기온 등 값을 제거합니다. 재시도 대기는 최대 1시간으로 늘어나며, 서버가 준 더 긴 요청 제한도 따릅니다.
- 숫자가 없는 항목은 0으로 꾸미지 않고 `—`로 표시합니다. 알 수 없는 날씨 코드는 상태 정보 없음으로 표시합니다.
- API 요청은 선택한 지역 좌표·격자를 외부 서비스에 전달합니다. GPS 자동 위치 수집이나 Tempos 프록시 서버는 사용하지 않습니다.
